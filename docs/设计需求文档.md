## 1. 背景与现状

淘街现有国内电商系统由三部分组成：`tjmall`（Java 微服务后端）、`plat`（平台管理后台）、`uniapp`（小程序/H5/App）。现有线上 PC 入口 `mall.taojieyph.com/static/html/pc.html` 只是一个外壳页：用 iframe 以约 375px 手机宽度嵌入移动端 H5，并非真正的 PC 商城，海外买家在电脑上无法正常浏览和询价。

在售商品除抽纸等日用品外，大量为汽车/工业漆料（1K/2K 色漆、珍珠、清漆、底漆等），具备出口展示价值。本项目新建一个面向海外买家的 PC 商城网站，解决三个问题：

1. **看得清**：真正的 PC 宽版布局（参照企叮咚首页骨架），英文为主、多语言切换；
2. **问得通**：海外买家以询价（RFQ）为主要转化路径，询价必须能真正到达销售端；
3. **跑得快**：站点与服务器都在海外，海外访客打开不绕国内。

## 2. 项目目标与范围

### 2.1 目标

- 建成可独立部署的海外 PC 商城：商品展示、分类、搜索、详情、询价闭环；
- 商品数据复用国内商城（`tjmall`）的真实商品，不重复录入；
- 后台可配置站点外观与基本信息，不必改代码即可调整主题、标题、联系方式、默认语言。

### 2.2 一期范围（本期做）

- PC 前端（已完成，见 §11）；
- 海外轻量后端：公开商品接口、询价入库与通知、站点配置接口（见 §6）；
- 商品数据从 `tjmall` 一次性导入 + 可重复执行的同步脚本；
- 部署到雅加达腾讯云服务器，阿里云 CDN 加速（见 §9）。

### 2.3 不做的范围

- 在线支付、订单、物流跟踪（一期只做展示 + 询价）；
- 会员注册/登录（海外展示站面向匿名访客）；
- 移动端 H5（海外移动端另行立项）；
- 改动 `tjmall`、`uniapp` 现有功能；`plat` 仅增加配置页，不改其既有页面逻辑。

## 3. 目标用户

| 用户 | 说明 |
|---|---|
| 海外经销商/批发商 | 主要目标：批量采购漆料与日用品，关注 MOQ、阶梯价、包装与交期，通过 RFQ 询价 |
| 海外零售小店 | 次要目标：小批量试单，关注样品与起订量 |
| 终端消费者 | 少量：以浏览为主，一期不提供下单 |

主要市场：东南亚（服务器位于雅加达）及公司现有出口市场；界面语言一期覆盖英、中、西、法、葡五种（见 §5.6）。

## 4. 总体架构

```
海外访客
   │  HTTPS
   ▼
阿里云 CDN ──────────────┐ （静态资源缓存：前端文件、商品图片）
   │ 回源               │
   ▼                    │
雅加达腾讯云服务器（Nginx）
   ├── /            → 前端静态站（taojie-pc-overseas 构建产物 dist/）
   └── /api/        → 海外轻量后端（新建项目）
                        ├── 商品目录 / 分类 / 搜索（公开只读）
                        ├── RFQ 询价（写入 + 通知销售）
                        ├── 站点配置（供前端读取、供 plat 配置页写入）
                        └── 数据库（商品多语言数据、询价、配置）
                                   ▲
                                   │ 同步脚本（从国内执行/定时任务）
国内 tjmall 数据库 ────────────────┘ （只读导出商品与分类）
plat 平台后台 ──── 配置页 ────→ 后端配置接口（二期直连；一期为文件导出过渡，见 §7）
```

架构要点：

- **后端新建、不运行时直连 tjmall**。理由：①跨境动态请求延迟高、不稳定，CDN 无法加速接口；②`tjmall` 的 front 接口是小程序登录模型，匿名请求返回 401，与公开展示站的访问模型不匹配；③海外站需要的英文商品名、美元价、MOQ、询价留资等字段 `tjmall` 不具备，硬改国内系统风险大；
- **数据用 tjmall 的、服务是海外独立的**：商品与分类从 `tjmall` 同步到海外库后，海外站不再依赖国内系统可用性；
- **前端与后端同机部署、经 CDN 对外**，接口与页面同域，避免跨域问题。

## 5. 前端需求（PC 站）

技术栈：Vue 3 + Vite，纯静态构建，无 UI 组件库依赖。仓库：`OrderDe/taojie-pc-overseas`。

### 5.1 首页布局

企叮咚式骨架 + 强冲击英雄区（已定版式，全站统一）：

- 顶栏：公告、登录/订单/帮助（占位）、语言切换、货币标签、主题切换；
- 页眉：Logo、搜索框、购物车入口；搜索热词行；
- 专区导航：礼品专区 / 自用专区 / 热门精选 / 涂料专区 / 案例 / 资讯（文案随语言切换）；
- 英雄区：左侧分类栏 + 全幅视觉主区（大标题、副标题、数据行）+ 右侧促销/经销商卡片；白色搜索胶囊压在英雄区下边缘；
- 品牌条、商品网格、询价区、页脚（含联系方式与演示数据标记位）。

### 5.2 商品展示

- 商品卡：主图区（图片缺失时用品牌色渐变占位，不允许破图）、分类、名称、价格（美元）、划线价、已售、MOQ；
- 商品详情：大图、价格、简介、参数表（混合比、干燥时间、覆盖率、保质期等）、MOQ 阶梯价提示、加入购物车、询价；
- 分类筛选与关键词搜索；无结果时有明确空状态文案。

### 5.3 主题系统

- 8 套完整主题（A 经典大商超 / B 跨境专业 / C 极简现代 / D 深色工业 / E 橙色脉冲 / F 编辑批发 / G 港口贸易 / H 色彩场），顶栏一键切换，访客选择记入浏览器本地存储；
- 管理员可在后台配置默认主题；访客自己的选择优先于管理员默认；
- 各主题共用同一版式公式（全幅英雄 + 大字标题 + 压线搜索胶囊），只换配色、字体与局部模块（如 D 的参数行、G 的阶梯价与英雄区询价表）。

### 5.4 购物车（展示型）

- 本地购物车：加入、移除、清空、合计金额；**不结算、不支付**，页面上明确标注为展示购物车，并引导用户改走 RFQ。

### 5.5 RFQ 询价

- 表单字段：姓名*、联系方式（邮箱或 WhatsApp）*、商品、数量、留言（目标市场、包装要求等）；
- 可从商品卡/详情页带商品名进入表单；
- 一期目标状态：提交后写入海外后端数据库并通知销售（见 §6.3）；当前前端为本地保存的过渡实现，后端就绪后切换为接口提交，表单与交互不变。

### 5.6 多语言

- 五种语言：English（默认）、中文、Español、Français、Português；顶栏下拉切换，整页即时切换，选择记入本地存储；
- 翻译范围：全部固定文案、8 套主题的英雄区文案；
- 商品数据（名称、分类、简介、参数）由后端按语言返回对应字段（见 §8）；接口未提供某语言时回退英文；
- 管理员可配置新访客的默认语言（`defaultLanguage`），访客自己的选择优先。

### 5.7 站点配置（前端侧）

前端启动时读取站点配置（现行一期机制为同目录 `pc-config.json` 文件，后端就绪后改为配置接口，字段保持一致）：

| 字段 | 含义 |
|---|---|
| `defaultTheme` | 默认主题（a–h） |
| `defaultLanguage` | 默认语言（en/zh/es/fr/pt） |
| `heroTitle` / `heroSubtitle` | 英雄区标题/副标题覆盖文案 |
| `announcement` | 顶栏公告 |
| `showRfq` | 是否显示询价模块 |
| `whatsapp` / `email` | 页脚联系方式 |
| `currency` | 货币标签（仅显示） |

## 6. 后端需求（新建海外轻量后端）

### 6.1 定位与技术要求

- 独立新项目，部署于雅加达腾讯云服务器，与前端同机；
- 只承担四件事：商品目录、询价、站点配置、数据同步导入；不做支付、订单、会员；
- 接口全部 HTTPS，经 Nginx 反代对外，路径前缀 `/api/`。

### 6.2 商品接口（公开只读，无需登录）

| 接口 | 说明 |
|---|---|
| `GET /api/categories?lang=` | 分类树（按语言返回名称） |
| `GET /api/products?lang=&keyword=&categoryId=&page=&limit=` | 商品列表（分页、搜索、分类筛选） |
| `GET /api/products/{id}?lang=` | 商品详情（简介、参数、阶梯价信息） |
| `GET /api/keywords?lang=` | 搜索热词 |

- 响应字段与前端现有数据层对齐（前端 `src/api.js` 已按此结构做归一化，后端按约定字段返回即可切换，前端改动最小）；
- 公开接口只允许读操作；加基础限流与缓存头，配合 CDN/网关缓存减轻源站压力。

### 6.3 询价接口

| 接口 | 说明 |
|---|---|
| `POST /api/rfq` | 提交询价：姓名、联系方式、商品、数量、留言、来源页面、语言、提交时间、访客 IP |
| `GET /api/admin/rfq`（需鉴权） | 询价列表查询，供销售跟进（一期可先用数据库直查/简单后台，二期进 plat） |

- 提交成功后触发通知：邮件通知到销售邮箱（必做）；WhatsApp 通知为可选项（二期评估）；
- 防刷：同 IP 频率限制 + 基础校验（联系方式格式），不使用验证码（降低海外买家提交门槛）。

### 6.4 站点配置接口

| 接口 | 说明 |
|---|---|
| `GET /api/site-config` | 前端读取，字段同 §5.7 |
| `PUT /api/admin/site-config`（需鉴权） | plat 配置页写入（二期直连；一期 plat 导出 `pc-config.json` 文件过渡） |

### 6.5 管理鉴权

- 一期从简：管理类接口使用独立的管理员令牌（环境变量配置），不与 `tjmall`/plat 账号体系打通；
- 二期再评估与 plat 登录态打通。

## 7. 管理端需求（plat 配置页）

- 位置：plat → 系统设置 → PC 商城设置 → 海外PC站配置（已建成，分支 `feature/overseas-pc-config`，待合并主线并本地构建验证一次）；
- 可配项与 §5.7 字段一一对应：默认主题（A–H 下拉）、英雄区标题/副标题、顶栏公告、是否显示询价、WhatsApp、联系邮箱、货币标签；
- **待补**：默认语言（`defaultLanguage`）字段——前端与配置文件已支持，配置页界面尚未加该项，二期补齐并改为直连 §6.4 接口保存。

## 8. 数据需求

### 8.1 商品数据模型（海外库）

在 `tjmall` 商品字段基础上扩展多语言与外贸字段：

| 字段 | 来源 | 说明 |
|---|---|---|
| `id` / `sourceId` | tjmall | 海外库主键 + tjmall 商品 ID（同步对账用） |
| `categoryId` | tjmall | 分类关联（分类同样多语言） |
| `name`（zh） | tjmall | 中文原名 |
| `nameEn` / `nameEs` / `nameFr` / `namePt` | 翻译维护 | 英文为必填（海外站默认语言），其余可后补，缺失回退英文 |
| `image` | tjmall | 商品图（同步时转存/引用，须保证海外可访问、过 CDN） |
| `price` / `otPrice` | tjmall 换算或独立定价 | 美元价；换算汇率与定价口径由业务确认（见 §12） |
| `unit` / `moq` | tjmall / 业务补充 | 计量单位、最小起订量 |
| `sales` | tjmall | 已售（展示用） |
| `blurb`（多语言） | tjmall 简介翻译 | 一句话简介 |
| `specs`（多语言键值） | tjmall 参数 | 如混合比、干燥时间、覆盖率、保质期等 |

### 8.2 数据同步

- 一期：一次性导入脚本，从 `tjmall` 数据库只读导出商品与分类，写入海外库；脚本可重复执行（按 `sourceId` 增量更新）；
- 商品英文名来源（一期）：先以「机器翻译 + 人工抽检」生成 `nameEn`，重点商品（漆料类）人工校准；不阻塞上线；
- 图片：须验证海外访问速度，必要时同步转存到雅加达服务器本地磁盘并走 CDN，不长期依赖国内图床直链；
- 定时自动同步为二期事项，一期手动执行脚本即可。

## 9. 部署与运维

| 项 | 方案 |
|---|---|
| 源站 | 腾讯云服务器（雅加达），Nginx 托管前端静态文件 + 反代后端接口 |
| 加速 | 阿里云 CDN：静态资源与商品图缓存；接口路径（`/api/`）不缓存或短缓存并正确配置回源 |
| 域名与证书 | **待提供**：海外站正式域名 + HTTPS 证书（CDN 侧配置） |
| 发布流程 | 前端：本地/CI 构建 `dist/` → 上传服务器目录 → 刷新 CDN 缓存；后端：打包部署 + 重启服务 |
| 环境隔离 | 后端配置（数据库密码、管理员令牌、邮件 SMTP）走服务器环境变量，不进代码仓库 |
| 日志与备份 | 后端日志留存 30 天；数据库每日备份（询价数据为核心资产，不可只存一台机器无备份） |

## 10. 非功能需求

- **性能**：CDN 命中时首屏可交互 < 2.5s（东南亚网络环境）；接口 P95 < 800ms（源站直连口径）；
- **可用性**：海外后端故障不得影响国内 `tjmall`/小程序业务（完全解耦）；前端在接口不可用时自动回退内置演示数据并明确标注（现行机制保留，作为降级手段）；
- **安全**：公开接口只读；管理接口必须鉴权；RFQ 接口限流防刷；所有配置与密钥不入库不进仓；
- **SEO 基础**：页面标题/描述可配（随站点配置），商品详情 URL 含商品 ID，后续可扩展 sitemap（一期不做）；
- **兼容性**：主流桌面浏览器最新两版（Chrome/Edge/Firefox/Safari）；仅 PC 宽屏布局，不做移动端适配（一期）。

## 14. 验收标准

1. 海外域名打开首页 < 2.5s（CDN 命中），8 套主题、5 种语言切换无错位、无未译固定文案；
2. 商品列表/详情/搜索展示的是 `tjmall` 同步来的真实商品（非演示数据），页脚无 Demo 标记；
3. 提交一条 RFQ：后端数据库可查到该记录，销售邮箱 5 分钟内收到通知；
4. 在 plat 配置页修改默认主题与公告并发布后，前台刷新即生效（M2 后为接口直连，M2 前为文件发布口径）；
5. 断开海外后端时，前端自动回退演示数据并显示标记，页面不白屏。
